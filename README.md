# YTasks - Task Manager

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![React](https://img.shields.io/badge/React-18.x-blue.svg)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-5.x-brightgreen.svg)](https://vitejs.dev/)

A modern, responsive task management application built with React.js. Manage your daily tasks efficiently with real-time persistence, completion tracking, and intuitive editing capabilities.

## ✨ Features

- ✅ **Add Tasks** - Quickly add new tasks with confirmation
- ✅ **Mark Complete** - Checkbox to mark tasks as completed with visual strikethrough
- ✅ **Edit Tasks** - Inline editing with confirmation dialogs
- ✅ **Delete Tasks** - Remove unwanted tasks with smooth animations
- ✅ **Persistent Storage** - Tasks saved automatically to localStorage
- ✅ **Filter Completed** - Toggle to show/hide completed tasks
- ✅ **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- ✅ **Real-time Updates** - Instant state synchronization across all features
- ✅ **Input Validation** - Minimum 3 characters required for new tasks
- ✅ **Professional UI** - Tailwind CSS powered modern interface

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/ytasks.git
cd ytasks

# Install dependencies
npm install

# Start development server
npm run dev
